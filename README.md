# 🏥 Healthcare Appointment & Prescription System (Frontend)

A modern React-based frontend for a healthcare system where patients can book appointments, doctors manage consultations, and prescriptions are handled digitally.

---

## 🚀 Live Demo

- 🌐 Frontend: https://healthcare-frontend-snowy.vercel.app/

> ⚠️ Backend may take a few seconds to wake up due to free hosting.

---

## ✨ Features

- 🔐 JWT Authentication (Login / Register)
- 👤 Role-based access (Admin, Doctor, Patient)
- 🧑‍⚕️ Browse doctors & book appointments
- 📅 View appointment history
- 📄 Download prescriptions (PDF)
- ⚡ Smooth UX with loading states & toast notifications

---

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS
- Axios
- React Router
- React Hot Toast
